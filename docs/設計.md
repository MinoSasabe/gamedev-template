## データ
| オブジェクト | 持っている情報 |
| ----------- | ---------- |
| プレイヤー | 座標(x,y)、半径、移動速度、HP |
| 迷路の壁 | 座標(x,y)、幅、高さ |
| 鍵 | 宝箱を開けたときに取得する。個別のオブジェクトとしては配置しない |
| 宝箱 | 座標(x,y)、当たり/外れ、開封済みかどうか |
| HUD | 集めた鍵の数、残り時間、操作案内 |
| ゲーム状態 | タイトル、プレイ中、ポーズ中、クリア、ゲームオーバー |

## 状態の移り変わり
- タイトル --Enterキー---->プレイ中
- プレイ中 --Escキー----> ポーズ中
- ポーズ中 --Escキー---->プレイ中
- プレイ中 --タイマーが0----> ゲームオーバー
- プレイ中 --HPが0----> ゲームオーバー
- プレイ中 --鍵を5個取得後に扉でEnter----> クリア
- クリア --Enterキー---->タイトル
- ゲームオーバー --Enterキー---->タイトル

## パラメータ
- プレイヤーの基準速度 = 200
- 鍵1個につき速度を8減少させる（最低速度140）
- 壁から12px以内では環境補正として速度を0.75倍にする
- プレイヤーの半径 = 20
- プレイヤーの初期HP = 10
- 近接攻撃力 = 1
- 近接攻撃射程 = 56px
- 近接攻撃クールダウン = 450ms
- 近距離敵の数 = 4
- 近距離敵の速度 = 72
- 近距離敵の接触ダメージ = 1
- 遠距離敵の数 = 1
- 遠距離敵のHP = 2
- 遠距離敵の弾速 = 105
- 遠距離敵の発射間隔 = 1500ms
- 遠距離敵の弾は3方向へ広がる
- 視界範囲 = プレイヤーを中心とした520×520px
- カメラの初期ズーム = 1.1倍
- カメラのズーム範囲 = 1.0〜1.8倍
- マウスホイールで0.1倍ずつズーム変更
- カメラは迷路の部屋領域をBoundsとして使用し、領域外へ移動しない
- 壁の背後へ暗い影を描画し、視界を遮る
- 当たりの宝箱の数 = 5
- 外れの宝箱の数 = 5
- タイマーの初期値 = 60
- 宝箱の操作可能距離 = 64
- 迷路の壁の厚さ = 15
- 迷路の開口部 = 96

## 宝箱
- 近づいてEnterキーを押すと開く
- 1度開けた宝箱にEnterキーを押しても何もならない
- 宝箱は全部で10個配置する
- ゲーム開始時に10個のうち5個をランダムに当たりへ設定する
- 当たりの宝箱を開けると鍵の取得数が1増える
- はずれの宝箱を開けても鍵の取得数は増えない
- はずれの宝箱には専用エフェクトを表示しない

## 迷路
- 21列×9行のグリッドを使い、ゲーム開始ごとにDFSで複雑な迷路を生成する
- DFS生成後、一部の壁を開けて複数の経路と迂回路を追加する
- 開始地点から全通路がつながる構成にする
- 壁セルを連続区間ごとの横壁・縦壁へまとめて描画する
- 壁の厚さは15pxとする
- プレイヤーと壁が重ならないように移動位置を制限する
- マスの幅は約84px、マスの高さは約93pxとする（従来の約1.5倍）
- 通路はプレイヤーの直径40pxより広くする
- 宝箱は生成された通路セルから10個選んで配置する
- 脱出扉は宝箱と開始地点を除く通路セルから1個選んで配置する
- 鍵を5個取得するまで脱出扉では脱出できない

## 画面構成
- `TitleScene`: Enterキーでゲームを開始する
- `GameScene`: 迷路、プレイヤー、宝箱、HUD、タイマーを表示する
- `ResultScene`: クリアまたはゲームオーバーを表示し、Enterキーでタイトルへ戻る
- 画像アセットは使用せず、PhaserのGraphicsとTextで描画する

## タイトル画面
- ゲームの目的、操作方法、制限時間、クリア条件を日本語で表示する
- 迷路をイメージした背景装飾を表示する
- `Enterキーでゲーム開始` の案内を点滅させる

## 鍵取得エフェクト
- 当たりの宝箱を開けたときだけ発生する
- プレイヤーの周囲にリングを表示し、拡大しながら消す
- プレイヤー上部に鍵の絵を表示し、拡大しながら消す
- HUDの鍵数表示を一時的に拡大する
- 5個目の鍵取得時は演出終了後にクリア画面へ遷移する
