# 要件定義書

## 1. どんなゲーム？

時間内に迷路を進み、宝箱から鍵を集めて部屋から脱出するゲーム。

操作：WASDキーまたは矢印キーで上下左右に動く。宝箱の近くでEnterキーを押すと開く。Spaceキーで攻撃、Escキーでポーズする。

タイトル画面では、ゲームの目的と操作方法を日本語で説明する。

## 2. 勝ち条件 / 負け条件

- 勝ち：鍵を3つ集めた状態で、迷路内の脱出扉をくぐる
- 負け：時間が0になったらゲームオーバー

## 3. 作らないもの

- BGM と効果音は作らない
- ステージは1つだけ。2面以降は作らない
- セーブ機能・ランキングは作らない

## 4. これができたら完成

1. プレイヤーが矢印キーで上下左右に動く
2. プレイヤーが迷路の壁を通り抜けずに移動できる
3. 宝箱の近くでEnterキーを押すと宝箱が開く
4. 当たりの宝箱を開けると、鍵の数が1増える
5. 鍵を3つ集めた状態で脱出扉をくぐるとクリア画面が出る
6. 当たりの宝箱はゲーム開始ごとにランダムで変わる
7. 迷路の壁配置はゲーム開始ごとにランダムで変わる
8. はずれの宝箱もある
9. 1度開けた宝箱は再度Enterキーを押しても反応しない
10. 残り時間が0になるとゲームオーバー画面が出る
11. クリア画面またはゲームオーバー画面でEnterキーを押すとタイトル画面に戻る
12. 当たりの宝箱から鍵を入手したときに鍵の絵のエフェクトが表示される
13. 未発見の脱出扉は、壁に開口部があると推測できないように表示される
14. 敵は迷路内の最短経路でプレイヤーを追い、被弾後0.2秒間は速度が半分になる
15. プレイヤーの近接攻撃は0.2秒間隔で行え、攻撃後0.1秒してからエネルギーを0.2秒分消費する
16. 残り時間はゲーム中と結果画面で小数点以下3桁まで表示される
17. ゲーム中の上部UIは5区画に分かれ、操作・次の指示・HP/EG・残り時間を表示する
18. ミニマップの経路・壁・扉・プレイヤー表示と「MAP」ラベルが拡大される
19. 鍵を3つ集めて扉を発見すると、プレイヤーの周囲に扉の方向が表示される
