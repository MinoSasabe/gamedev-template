# 要件定義書

## 1. どんなゲーム？

時間内に迷路を進み、宝箱から鍵を集めて脱出扉から部屋を脱出するゲーム。

操作：矢印キーで上下左右に動く。宝箱や脱出扉の近くでEnterキーを押す。Spaceキーで近接攻撃をする。Escキーでポーズする。

タイトル画面では、ゲームの目的と操作方法を日本語で説明する。

## 2. 勝ち条件 / 負け条件

- 勝ち：当たりの宝箱から鍵を5つ集め、脱出扉の近くでEnterキーを押したらクリア
- 負け：時間が0になる、またはプレイヤーのHPが0になるとゲームオーバー

## 3. 作らないもの

- BGM と効果音は作らない
- ステージは1つだけ。2面以降は作らない
- セーブ機能・ランキングは作らない

## 4. これができたら完成

1. プレイヤーが矢印キーで上下左右に動く
2. プレイヤーが迷路の壁を通り抜けずに移動できる
3. 宝箱の近くでEnterキーを押すと宝箱が開く
4. 当たりの宝箱を開けると、鍵の数が1増える
5. 当たりの宝箱を5つ開けると脱出扉が開く
6. 鍵を5つ集めた後、脱出扉の近くでEnterキーを押すとクリア画面が出る
7. 当たりの宝箱はゲーム開始ごとにランダムで変わる
8. 迷路の壁配置はゲーム開始ごとにランダムで変わる
9. 脱出扉はゲーム開始ごとにランダムな通路へ配置される
10. はずれの宝箱もある
11. 1度開けた宝箱は再度Enterキーを押しても反応しない
12. 残り時間が0になるとゲームオーバー画面が出る
13. クリア画面またはゲームオーバー画面でEnterキーを押すとタイトル画面に戻る
14. 当たりの宝箱から鍵を入手したときに鍵の絵のエフェクトが表示される
15. プレイヤーの周囲だけが見え、マップ全体は一度に見えない
16. カメラがプレイヤーを追従し、マウスホイールでズームを変更できる
17. カメラが迷路の外へ移動せず、壁の背後が暗くなる
18. 近距離型の敵がプレイヤーを追跡し、接触するとHPが減る
19. 近接攻撃で近距離型の敵を倒せる
20. 遠距離型の敵が低速の弾を発射する
21. 遠距離型の敵の弾が壁に当たると消える
